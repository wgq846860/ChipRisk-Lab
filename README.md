# 芯链决策器 ChipRisk Lab

《数字经济导论》课程简报的交互式附录：用六项参数模拟算力平台迁移难度、供应风险及效率—韧性权衡。

公开访问：<https://wgq846860.github.io/ChipRisk-Lab/>

## 功能

- AI 创业公司、大型互联网企业、科研机构三类场景预设
- 六项 1～5 档参数控制
- 迁移难度、供应风险、综合脆弱性评分
- 风险结构雷达图与效率—韧性矩阵
- 成本与扩散、创新与组织、可得性与风险三条解释路径
- 完整公式、局限和参考资料说明

## 评分公式

迁移难度：

```text
0.35 × 平台依赖度
+ 0.35 × 软件迁移复杂度
+ 0.20 × (6 - 替代平台成熟度)
+ 0.10 × (6 - 企业适配能力)
```

供应风险：

```text
0.45 × (6 - 供应稳定性)
+ 0.25 × 平台依赖度
+ 0.20 × 成本敏感度
+ 0.10 × (6 - 企业适配能力)
```

综合脆弱性：

```text
0.55 × 供应风险 + 0.45 × 迁移难度
```
